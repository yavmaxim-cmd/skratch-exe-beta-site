# SKRATCH.EXE Beta Site

Статическая страница загрузки SKRATCH.EXE 0.9.0-beta для Windows x64. Откройте `index.html` в браузере. Кнопки загрузки ведут на файлы предрелиза `v0.9.0-beta.1` в разделе Releases этого репозитория.

Сайт использует относительные пути для собственных стилей и графики. GitHub Pages публикуется из ветки `main` через workflow `Deploy static site to Pages`.
