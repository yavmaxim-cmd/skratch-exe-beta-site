# SKRATCH.EXE Beta Site

Статическая страница загрузки SKRATCH.EXE 0.9.0-beta для Windows x64. Откройте `index.html` в браузере.

Чтобы ссылки на загрузку работали после клонирования, скопируйте установщик, portable ZIP и архив исходников сборки `86e2251` в папку `downloads/`. Имена файлов и их контрольные суммы указаны в `downloads/SHA256SUMS.txt`. Пакеты сборки хранятся отдельно от истории Git.

Репозиторий C++ плагина ведётся отдельно.
